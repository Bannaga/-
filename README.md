# تطبيق شجرة العائلة لأندرويد

هذا مشروع أندرويد جاهز يعرض صفحة شجرة العائلة كتطبيق مستقل على الجوال.

- يعمل بدون إنترنت، وكل تغيير يُحفظ تلقائيًا داخل التطبيق.
- زر «مشاركة» يرسل الشجرة كملف HTML واحد عبر واتساب أو البريد، ويفتحه الطرف الآخر في أي متصفح.
- إذا وصلك ملف شجرة، افتحه واختر «شجرة العائلة» فيُستورد إلى التطبيق.

## الطريقة الأولى: بناء التطبيق على GitHub (بدون تثبيت برامج)

تحتاج كمبيوتر وحسابًا مجانيًا على GitHub.

1. فك ضغط الملف `FamilyTreeApp.zip`.
2. ادخل إلى [github.com](https://github.com)، وأنشئ حسابًا إن لم يكن لديك.
3. اضغط **New repository**، واكتب اسمًا مثل `family-tree`، ثم **Create repository**.
4. اضغط **uploading an existing file**، واسحب **كل ما بداخل** مجلد `FamilyTreeApp` إلى الصفحة، ثم **Commit changes**.
5. افتح تبويب **Actions**. سيبدأ البناء تلقائيًا ويستغرق حوالي 5 دقائق.
6. عند ظهور العلامة الخضراء، افتح عملية البناء، ومن قسم **Artifacts** نزّل `family-tree-apk`.
7. فك ضغطه لتجد `app-debug.apk`. أرسله إلى جوالك وافتحه، واسمح بالتثبيت من مصادر غير معروفة عندما يُطلب منك.

**إذا كان تبويب Actions فارغًا:** المجلد المخفي `.github` لم يُرفع. اضغط **Add file ← Create new file**، واكتب الاسم:
`.github/workflows/build-apk.yml`
ثم الصق فيه محتوى الملف بنفس الاسم من المجلد، واضغط **Commit changes**.

## الطريقة الثانية: Android Studio

1. ثبّت [Android Studio](https://developer.android.com/studio) (مجاني).
2. اختر **Open** وافتح مجلد `FamilyTreeApp`، وانتظر حتى ينتهي التحميل الأول.
3. صِل جوالك واضغط ▶ **Run**، أو اختر **Build ← Build APK(s)** للحصول على ملف APK.

## تحديث الصفحة داخل التطبيق

الصفحة موجودة في `app/src/main/assets/index.html`. استبدلها بنسخة أحدث من `family-tree.html`، وارفع رقم `versionCode` في `app/build.gradle.kts`، ثم أعد البناء.

## ملاحظة مهمة

البيانات محفوظة داخل التطبيق على الجوال. **حذف التطبيق يحذف البيانات**، لذلك احفظ نسخة أو شاركها قبل الحذف أو تغيير الجوال.
